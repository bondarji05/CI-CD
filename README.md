
# CI/CD —  Calculator

Учебный Java-проект для изучения процессов непрерывной
интеграции и автоматизированного тестирования с использованием
GitHub Actions.

## Используемые технологии

- Java 21
- Apache Maven
- JUnit 5
- Git и GitHub
- GitHub Actions

## Функциональность

Приложение реализует базовые математические операции:

- Сложение двух целых чисел.
- Вычитание двух целых чисел.

## Структура проекта

- src/main/java — исходный код приложения.
- src/test/java — модульные тесты.
- pom.xml — конфигурация Maven.
- .github/workflows/main.yml — конфигурация CI/CD.

## Сборка проекта

mvn clean compile

## Запуск тестов

mvn test

## CI/CD

При отправке изменений в репозиторий GitHub Actions
автоматически выполняет компиляцию проекта и запуск
модульных тестов.
